# Laundry Management System

## 1. Project Overview
The Laundry Management System is a desktop application developed to help laundry businesses manage their daily activities efficiently. It simplifies the management of customers, laundry orders, payments, employees and deliveries.

The system aims to reduce manual record keeping, improve accuracy and make laundry business operations easier.

## 2. Technologies Used
- Java – Application development
- Java Swing – Graphical User Interface (GUI)
- MySQL – Database management
- JDBC – Database connectivity
- NetBeans IDE – Development environment

## 3. Main Features
- Customer management
- Employee management
- Laundry order management
- Laundry services management
- Payment management
- Delivery management
- Customer feedback management
- Reports generation
- User login and authentication

## 4. Database
The application uses a MySQL database named `laundry_db` to store and manage system information.

## 5. Development Environment
- NetBeans IDE
- WAMP Server
- MySQL Database
- Java Development Kit (JDK)

## 6. Project Purpose
This project was developed as part of an Object-Oriented Programming course to apply software development concepts to a real-world laundry business problem.
